# Zovril Messenger

A modern, feature-rich messenger inspired by WhatsApp Web, fully rebranded as **Zovril**.

## Features
- Real-time chats, voice notes, media sharing
- Audio & video calling UI
- Status / Stories
- Dark & Light theme
- Full Bengali + English support
- AI Assistant, Productivity tools, Lossless share, Storage manager
- Login portal (QR + Phone OTP simulation)

## Logo & Branding
- Official logo: `src/assets/images/zovril_logo.png`
- App icons (all shapes & sizes): `public/app-icons/` and root `zovril-icons/`

- **Square**: icon-16.png → icon-1024.png

## Run Locally

1. `npm install`
2. Set `GEMINI_API_KEY` in `.env.local` (optional for AI features)
3. `npm run dev`

Open http://localhost:3000
